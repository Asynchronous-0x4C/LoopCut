# 05. 描画規約

このゲームの見た目は完成度が高く、**追加要素はこの規約に従わないと明確に浮く。**
新しいタイル・オブジェクト・UI を描くときは必ずここを参照すること。

## 1. 三原則

1. **画像を使わない。** すべて `Graphics` によるベクター描画。
   例外はタイトルロゴのみ（`?raw` で読んだ SVG を `Graphics.svg()` に流す、[title.ts](../src/game/title/title.ts)）。
2. **すべての図形は「影 → 本体」の 2 回描き。** これが紙のような浮遊感を作っている（§3）。
3. **色は 1 系統のグレー + 差し色の赤/水色のみ。** 新しい色相を足さない（§2）。

| プレイヤー / ゴースト | `#646464` | |
| テキスト | `#646464` (`0x646464`) | |
| UI ドット | `#646464` | |
| スタート / ゴールの印 | `#e63333` | 差し色（赤） |
| スイッチ（未押下） | `#5fc3c9` | 差し色（水色） |
| スイッチ（押下済） | `#a4b1b2` | くすんだ水色 |

**新しい状態を表すときは、まず「alpha を変える」「線を増やす」で表現できないか考える。**
色相を増やすのは最後の手段。

## 3. 影の描き方（最重要）

すべての図形は次の順で 2 回描く。

```ts
const z = 3;   // 影のオフセット。全要素で共通

// 1) 影: (+z, +z) にずらして、薄い alpha で
g.circle(z, z, 10);
g.stroke({ width: 3, color: "#333333", alpha: 0.2 });

// 2) 本体: 原点に、濃い alpha で
g.circle(0, 0, 10);
g.stroke({ width: 3, color: "#333333", alpha: 0.8 });
```

- **オフセットは常に `z = 3`、右下方向**（`+x, +y`）。
- 影を**先に**描く（後から描いた本体が上に乗る）。
- テキストは Pixi の `dropShadow`（`distance: 3`）で同じ効果を出す。
- `ParticleContainer` を使う UI ドットは、**同じ粒を 2 セット**用意して片方を +3 ずらしている
  （[ui.ts](../src/game/ui/ui.ts)）。テクスチャは 1 枚だけ作って使い回す。

### alpha の目安

| 要素 | 影 | 本体 |
|---|---:|---:|
| タイル（線） | 0.2 | 0.8 |
| プレイヤー（塗り） | 0.3 | 0.9 |
| ゴースト・実体あり | 0.2 | 0.9 |
| ゴースト・実体なし | — | 0.5（影なし） |
| テキスト | 0.25 | 0.8 or 1.0 |

## 4. 寸法

| 対象 | 値 |
|---|---|
| 論理解像度 | 1280 x 720（中央は 640, 360）。定数は [screen.ts](../src/common/screen.ts) |
| グリッド間隔 `gap` | 60px（[field.ts](../src/game/stage/field.ts) の `Field.gap`） |
| 通常タイル | 半径 10 の円、stroke 3 |
| スタート / ゴール | 20x20 角丸 4 の枠 + 内側に赤い印（三角 / 8x8 の四角） |
| スイッチ | 通常タイル + 半径 5 の塗り円 |
| プレイヤー | 40x40 角丸 4 の塗り |
| ゴースト | 40x40 角丸 4 の stroke 5 枠 + 内側 28x28 角丸 2 の塗り |
| レーザー | 長さ 50、外光 4px / 芯 2px、両端に 8x6 の発振器 |
| UI ドット | 20x20 角丸 3、間隔 25px、y = 40 |
| 本文フォント | `Noto Sans JP` 25px（Google Fonts、[index.html](../index.html) で読み込み） |

**タイル 1 マス（60px）に対して図形は 20〜40px。** マスを埋め尽くさないのがこのゲームの空気感。

## 5. アニメーション規約

### 5.1 補間は一次遅れのみ

イージング関数は使わない。毎フレーム次の形で書く。

```ts
import { damp } from "../../common/interpolate";

v += (target - v) * damp(k, t.deltaTime);
```

| 対象 | `k` |
|---|---:|
| プレイヤー / ゴーストの移動 | 0.5 |
| タイルの alpha | 0.4 |
| UI ドットの alpha | 0.5 |
| タイトル文字のフェード | 0.5 |

`damp()`（[src/common/interpolate.ts](../src/common/interpolate.ts)）は
`1 - (1 - k) ** deltaTime` を返す。60fps（`deltaTime === 1`）では `k` そのものなので
**従来の見た目は変わらず**、高リフレッシュレートでも同じ速さで収束する。

> **新しい補間を書くときは必ず `damp()` を通すこと。** 生の係数を掛けるとフレームレート依存に戻る。

### 5.2 入退場は「マンハッタン距離の波」

[fieldanim.ts](../src/game/stage/fieldanim.ts) の `applyWave()`。ステージと選択画面で共有している。

```ts
const _m = tile.x + tile.y - field.manhattan.min;      // 左上からの距離
const x = Math.max(0, 10 + (20 / m * _m) - time) / 10; // タイルごとの遅延
g.pivot.y = SCREEN_HEIGHT * x * x * x * x * dir;       // 4 乗で加速
```

- 左上のタイルから順に、画面外から降ってくる／画面外へ落ちていく。
- `dir = 1` で下から、`dir = -1`（`End` 状態）で上へ抜ける。
- **飛距離は論理高さ 720（`SCREEN_HEIGHT`）で固定する。**
  `app.screen.height` はウィンドウに合わせて縮んだ実ピクセル値なので、
  これを使うと小さいウィンドウでタイルが画面外まで飛びきらず、
  演出の開始時に見えてしまう。
- **新しいオブジェクトを足したら `applyWave()` の `extra` に渡すこと。**
  忘れるとそのオブジェクトだけ画面に貼り付いたまま残る。

### 構築直後の 1 フレーム

シーンやステージを組み立てたフレームでは、まだ `update()` が回っていない。
**組み立て終わったら、その場で初期状態を 1 回適用すること。**
忘れると「完成形が 1 フレームだけ見える」ちらつきになる
（`StageView` はコンストラクタで、`Select` は `build()` の最後で適用している）。

### 5.3 点滅フェードイン

プレイヤー・ゴースト・UI は `time` が 45 を超えてから数フレーム点滅して現れる
（`entityAlpha()`, [fieldanim.ts](../src/game/stage/fieldanim.ts)）。

```ts
const x = Math.max(0, Math.min(time, 50) - 45);
alpha = clamp01(Math.ceil(Math.sin(x * Math.PI * 0.5)) * Math.ceil(x / 3));
```

元の式は -1 や 2 も返すので 0〜1 に丸めている（明滅のパターンは変わらない）。

タイトルロゴの退場も同じ式（[title.ts](../src/game/title/title.ts)）。
**「実体が明滅する」という世界観の表現なので、新しい実体系の要素にも適用すること。**

## 6. レイアウトの決まり

- フィールドは `Field.offset` で画面中央に寄せられる（タイル追加のたびに再計算）。
  タイルの絶対座標ではなく、実際に使っている範囲の中心が画面中央に来る。
- 操作説明テキストは左上 `(5, 30)`。
- 残歩数ドットは上端中央、`y = 40`。
- タイトル: ロゴ `(640, 200)`、「キーを押してスタート」`(640, 680)`。
- クリア画面のテキストは `(640, 360)`。

## 7. やってはいけないこと

- 画像アセット（PNG/JPG）を追加する。
- 影を省略する、または影の向き・オフセットを変える。
- 新しい色相（緑・黄・紫など）を足す。
- イージングライブラリを導入する。
- 図形をマス目いっぱい（60px）に描く。
- フォントを増やす。
