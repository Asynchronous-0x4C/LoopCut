**現行実装の事実**と**これからの方針**を分けて記述している。

## 用語

| 用語 | 意味 |
|---|---|
| **タイル (Tile)** | グリッド上の足場。`Unused`（未通過）と `Used`（通過済み＝進入不可）の 2 状態を持つ |
| **ループ (Loop)** | プレイヤーが動けるひと区切り。詰むか歩数を使い切ると終了し、ステージが再構築される |
| **ゴースト (Ghost)** | 直前のループでのプレイヤーの軌跡を逆再生する分身。前半は実体あり、後半は実体なし |
| **実体 (solid)** | ゴーストがタイルを `Used` にし、レーザーに阻まれる状態。`remainSteps > 0` の間 |
| **歩数 (steps)** | 1 ループでプレイヤーが動ける回数。画面上部のドット列で表示 |
| **詰み (jammed)** | 隣接する `Unused` タイルが 1 つも無い状態。即ループ終了 |
| **フィールド (Field)** | タイルとレーザーの集合。グリッド座標 → ワールド座標の変換も担う |
| **ワールド** | 選択マップ 1 枚。ステージのラベル `1-1` の左側の数字 |
| **入口 (exit)** | 選択マップ上のステージへの入り口。`&` タイルと、描画されないマーカーの組 |

## この文書群のメンテナンス方針

- **「事実」の章は実装と一致していなければならない。** ルールやデータ形式を変えたら同じコミットで更新する。
- 各記述には可能な限り `ファイル:行` の参照を付ける。行番号がずれても検索できるよう、関数名も併記する。
- 「方針」の章（07）は達成したら該当項目にチェックを入れ、履歴として残す。
